## LocalSend：局域网传输

适用：安装官方 LocalSend 客户端的设备。

1. 设备连接同一可信局域网，启动客户端。
2. 如系统防火墙提示，仅在确实可信的网络环境允许本地通信，不要直接关闭防火墙。
3. 在发送端选择小测试文件，核对接收设备名称；接收端确认后保存。
4. 验证文件内容和保存路径，按需关闭自动接收等选项。

无法发现设备时，先检查访客网络/AP 隔离、网络权限以及 VPN 路由；不要把发现端口映射到公网。
撤销：退出应用，按系统方式移除不再需要的防火墙授权。

[官方项目与最新版本](../software/localsend.md)

## PowerToys：按需启用模块

适用：Windows，具体兼容版本以上游说明为准。

1. 使用对应架构的官方安装包，启动设置。
2. 一次只启用需要的模块，例如 FancyZones 或 PowerToys Run。
3. 检查模块快捷键与现有输入法、软件快捷键是否冲突，修改后做实际测试。
4. 涉及管理员权限的功能，只在确实需要时启用，不默认提权。

撤销：关闭相关模块或恢复原快捷键；完整退出应用验证是否恢复原行为。

[官方项目与最新版本](../software/powertoys.md)
