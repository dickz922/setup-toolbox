## 上游更新说明（原文）

以下为上游原文的纯文本展示；官网来源可能提供完整历史日志，不仅当前版本。

```text
### Major updates

- **New desktop updater.** Start an update and Electerm automatically downloads the new version from the fastest available mirror. Once you confirm installation, the updater closes Electerm, replaces the old files, and reopens the app (#4812)
- **Search bookmarks with multiple keywords.** Type `prod web` to find bookmarks matching both words. Add `!backup` to leave backup entries out of the results (#4830) by @wsaaaqqq
- **Restore your workspace on startup.** Enable workspace restoration in Settings to reopen your layout and bookmarked tabs the next time you start Electerm (#4822)
- **Manage SSH tunnels during a session.** Add, start, or stop tunnels from the session toolbar (#4808)

### Improvements

- Electerm starts faster on Windows thanks to improved certificate loading (#4807)

### Security fix

- Fixed an issue where a folder name could trigger an unintended command when Electerm changed directories in a Windows terminal such as Git Bash or WSL (#4809)

### Bug fixes

- SSH tabs now stay open after an idle timeout so you can read the last terminal output
- Fixed a startup issue with the Linux `.tar.gz` download (#4819)
- Fixed a shortcut that could paste selected terminal text twice (#4821)

-----

### 重大更新

- **新版桌面更新程序。** 开始更新后，Electerm 会自动从最快的镜像站下载新版。确认安装后，更新程序会自动关闭 Electerm、替换旧文件，再重新打开应用 (#4812)
- **书签搜索支持多个关键词。** 输入 `prod web` 可以找到同时匹配这两个词的书签，再加上 `!backup` 就能排除包含 `backup` 的结果 (#4830) by @wsaaaqqq
- **启动时恢复工作区。** 在设置中开启后，下次启动 Electerm 时会恢复上次的布局，并重新打开之前从书签打开的标签页 (#4822)
- **在会话中管理 SSH 隧道。** 可以直接从当前会话的工具栏添加、启动或停止隧道 (#4808)

### 性能改进

- 优化了 Windows 上的证书加载，让 Electerm 启动更快 (#4807)

### 安全修复

- 修复了 Electerm 在 Windows 的 Git Bash、WSL 等终端中切换目录时，特定文件夹名称可能导致终端意外执行命令的问题 (#4809)

### 问题修复

- SSH 会话因空闲超时断开后，标签页会保持打开，方便查看最后的终端输出
- 修复了 Linux 版 `.tar.gz` 安装包解压后可能无法启动的问题 (#4819)
- 修复了用快捷键粘贴终端选中文字时可能重复粘贴的问题 (#4821)

-------

Download下载: [https://electerm.org](https://electerm.org)
```
