## 上游更新说明（原文）

以下为上游原文的纯文本展示；官网来源可能提供完整历史日志，不仅当前版本。

```text
### New features/UI/Updates

- Search for sessions by name and close them directly from the session list (#4797)
- Access sharing options directly from each bookmark row (#4790)
- When dragging files into the terminal to upload them, choose whether to overwrite an existing file or rename the upload (#4786)
- Give labels in trees and lists more room when fewer controls are visible
- Simple widgets can now include their own asset files
- Show widget controls and built-in widget names in the selected language (#4778)

### Bug fixes

- Preserve in-progress Sogou Pinyin input when pressing Shift in the terminal (#4800)
- Start sending SSH keepalive messages only after authentication succeeds (#4798)
- Fix the connection test for FTP bookmarks (#4796)
- Prevent directory names from being interpreted as commands when Electerm changes directories in PowerShell (#4793)
- Fix scrolling in the transfer history (#4792)
- Fix SFTP directory tracking when the SSH terminal is waiting at a prompt (#4791)

-----

### 新功能/界面/更新

- 支持在会话列表中按名称搜索会话，也可以直接关闭会话 (#4797)
- 支持在书签列表中直接打开每个书签的分享选项 (#4790)
- 将文件拖入终端上传时，如遇同名文件，可选择覆盖已有文件或重命名要上传的文件 (#4786)
- 树形视图和列表会根据可见按钮的数量调整标签宽度，按钮较少时可显示更长的名称
- 简单小组件现在可以自带资源文件
- 小组件的控件和内置小组件的名称会随界面语言切换 (#4778)

### Bug 修复

- 修复在终端使用搜狗拼音时按 Shift 会丢失正在输入的拼音的问题 (#4800)
- SSH 连接现在会等到身份验证成功后才发送保活消息 (#4798)
- 修复 FTP 书签的连接测试功能 (#4796)
- 修复 Electerm 在 PowerShell 中切换目录时可能将目录名当作命令执行的问题 (#4793)
- 修复传输历史记录的滚动问题 (#4792)
- 修复 SSH 终端停在命令提示符时 SFTP 目录未能跟随切换的问题 (#4791)

-------

Download下载: [https://electerm.org](https://electerm.org)
```
