# 装机与软件安装检查清单

适用：Windows、macOS、Linux 新装或重装后的通用检查。本页人工维护，不是自动执行脚本。

## 1. 重装前

- 备份文档、照片、浏览器资料、密钥、软件许可证与必要的配置。
- 抽查备份能否恢复；仅存在同一磁盘另一个分区不算独立备份。
- 保存系统恢复密钥；确认系统镜像来自操作系统官网。
- 制作启动盘前检查设备容量、型号，拔掉不相关移动硬盘。

**Ventoy 初次安装可能格式化目标 U 盘。未核对目标、未备份，不要继续。**

## 2. 系统就绪

- 安装系统安全更新、官方驱动，重启并检查设备状态。
- 启用磁盘加密前先保存恢复密钥，确认备份方案。
- 配置标准用户、自动锁屏与可靠备份；不要为了“优化”关闭安全防护。

## 3. 安装配套软件

从[软件目录](../software/README.md)选择所需工具，不追求一次装满。

- 按系统和 CPU 架构选择包，例如 x64、ARM64；便携版与安装版不要混淆。
- 使用上游 HTTPS 下载地址，查看签名或官网校验值，不使用来历不明整合包。
- 逐一安装和验证，再按需配置开机启动，避免批量安装后难以定位问题。

## 4. 验证与回退

验证压缩包解压、跨设备传输、常用快捷键、备份恢复与外设工作正常。
记录人工修改；修改配置前保存原文件，异常时恢复。系统级改动优先使用系统恢复机制，不在未知环境套用一键优化命令。
